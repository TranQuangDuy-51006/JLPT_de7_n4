# LĐN4 – Đề 7 | Quizizz thuần Frontend

## Cấu trúc
- `index.html`: giao diện
- `style.css`: CSS, có xử lý font Nhật/Unicode và gạch chân
- `app.js`: toàn bộ dữ liệu câu hỏi, đáp án, logic quiz

## Chạy
Không cần Node.js, React hay backend.

Chỉ cần mở `index.html` bằng trình duyệt.

## Đúng theo yêu cầu
- Thuần HTML/CSS/JavaScript.
- Nội dung lấy từ 2 PDF được cung cấp.
- Phần đọc hiểu hiển thị nguyên đoạn văn làm đề bài.
- Các vị trí từ/cụm từ cần gạch chân dùng `<u>` + CSS.
- Phần nghe chỉ hiển thị lựa chọn đáp án; phần đề bài để placeholder để DEV tự thêm ảnh/audio.
- UTF-8 và font stack Nhật: Noto Sans JP → Hiragino Kaku Gothic ProN → Yu Gothic → Meiryo → system-ui.
- Có chấm điểm và xem lại đáp án.
- Không dùng thư viện ngoài.

## Lưu ý phần nghe
Các câu có lựa chọn hình ảnh trong PDF được để `DEV thêm ảnh` thay vì tự chèn ảnh PDF, đúng yêu cầu.
